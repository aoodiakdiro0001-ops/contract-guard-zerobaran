## 📖 ما هو Contract-Guard ZeroBaran؟

هو **نظام ذكي متكامل ومستقل** لقراءة العقود القانونية (NDAs، عقود العمل، اتفاقيات الشراكة، أو شروط الخدمة)، فحص بنودها بدقة لاستخراج المخاطر والثغرات الخفية، مقارنتها بالمعايير العادلة، وتوليد مسودات اتفاقيات قانونية محكمة.

يقوم النظام بـ:
1. **استلام** المستند القانوني (ملف PDF أو نص)
2. **تحليل** كل بند على حدة
3. **تحذيرك** من الشروط المجحفة أو التزامات الضمان الخفية
4. **تقديم** صياغات بديلة آمنة

دون دفع دولار واحد لأي أستوديو قانوني أو أداة مراجعة مدفوعة، وبموارد مجانية بالكامل.

## 💡 لماذا تحتاجه كل شركة وكل مستقل؟

### 💰 توفير مال فلكي
مراجعة العقود واستشارة المحامين لكل اتفاقية جديدة تكلف مبالغ طائلة؛ هذا النظام يؤدي نفس الغرض باحترافية قانونية مذهلة وبتكلفة صفر.

### ⚠️ الكشف المبكر عن الفخاخ القانونية (Zero Risk Blindspots)
يمنعك من توقيع عقود تحتوي على:
- غرامات خفية
- شروط جزائية مجحفة
- تنازلات غير مقصودة عن حقوق الملكية الفكرية
- التزامات تعويضية مفتوحة

### 🔒 السيادة والسرية التامة
عقودك الحساسة، اتفاقيات عملك، والبيانات المالية لا تُشارك مع أي جهات خارجية بل تُعالج في بيئة سرية خاصة بك.

## 📐 البنية البرمجية والتصميم الهندسي

يتكون النظام من **4 طبقات برمجية ذكية** تتناغم لتعمل كمستشار قانوني رقمي خاص بك:

```
[إرسال عقد أو اتفاقية قانونية (PDF / Word) عبر تليجرام أو واجهة الويب]
                                  │
                                  ▼
[Python + PyMuPDF (تفكيك المستند واستخراج النصوص والبنود القانونية بدقة)]
                                  │
                                  ▼
[Google Gemini API (تحليل المخاطر، كشف الثغرات، واقتراح التعديلات الآمنة)]
                                  │
                                  ▼
[تخزين التقرير في Supabase ──► إرسال تقرير المخاطر وملخص التوصيات إلى تليجرام]
```

### تفصيل الطبقات برمجياً:

#### 1️⃣ طبقة الاستقبال والقراءة القانونية (Ingestion & Parsing Layer)
- **التقنية:** سكريبت بايثون باستخدام مكتبة PyMuPDF أو python-docx
- **الآلية:** يستلم ملف العقد، يفرغ نصوصه بالكامل، وينظم البنود والفصول القانونية لتسهيل تحليلها آلياً
- **الملفات:** `src/parsers/pdf_parser.py`, `src/parsers/docx_parser.py`, `src/parsers/contract_segmenter.py`

#### 2️⃣ العقل القانوني والذكاء الاصطناعي (AI Legal Analysis Core)
- **التقنية:** استغلال Gemini API (أو Groq API كبديل)
- **الآلية:** مزود ببروتوكولات تحليل قانوني دقيقة: "راجع هذا العقد كخبير قانوني. حدد أي بند يشكل خطراً أو غرامة غير عادية، كشف الشروط المجحفة، واقترح صياغة بديلة تحمي حقوقنا"
- **الملفات:** `src/ai/gemini_analyzer.py`, `src/ai/groq_analyzer.py`, `src/ai/prompts.py`

#### 3️⃣ طبقة الأرشيف وقاعدة البيانات (Persistence Layer)
- **التقنية:** قواعد بيانات Supabase (PostgreSQL مجاني)
- **الآلية:** تحفظ العقود المدروسة، تقارير المخاطر، وحالة كل اتفاقية (مقبولة، تحتاج تعديل، مرفوضة) لسهولة الرجوع إليها
- **الملفات:** `src/database/supabase_client.py`, `src/database/schema.sql`

#### 4️⃣ طبقة التوصيل والتسليم الفوري (Delivery & Control)
- **التقنية:** Telegram Bot + Streamlit Dashboard
- **الآلية:** يرسل لك تقريراً فورياً ومنظماً على هاتفك:
- **الملفات:** `src/delivery/telegram_bot.py`, `dashboard/streamlit_app.py`

## ⚙️ طريقة العمل خطوة بخطوة (End-to-End Workflow)

1. **الحدث:** يرسل لك عميل أو شريك مشروع عقد عمل أو اتفاقية شراكة بصيغة PDF عبر بوت تليجرام المخصص.
2. **المعالجة الآلية:** يستلم النظام الملف، يفكك نصوصه، ويجهز الفصول القانونية للتحليل خلال ثوانٍ معدودة.
3. **التشريح وكشف المخاطر:** يمرر الذكاء الاصطناعي البنود على معايير الأمان القانوني ويصنف المخاطر (عالية، متوسطة، منخفضة).
4. **النتيجة الفورية:** يأتيك تقرير مفصل وفوري على هاتفك يحذر من الثغرات ويقترح التعديلات، وتُحفظ البيانات في لوحة تحكم سحابية.

## 🚀 التثبيت والتشغيل

### المتطلبات
- Python 3.10 أو أحدث
- مفاتيح API مجانية (انظر قسم الإعداد)

### الخطوة 1: تثبيت المتطلبات
```bash
cd Contract-Guard-ZeroBaran
pip install -r requirements.txt
```

### الخطوة 2: إعداد متغيرات البيئة
```bash
cp .env.example .env
# حرّر ملف .env واملأه بمفاتيحك المجانية
```

### الخطوة 3: إعداد قاعدة البيانات
1. أنشئ حساباً مجانياً على [Supabase](https://supabase.com)
2. أنشئ مشروعاً جديداً
3. افتح SQL Editor والصق محتوى `src/database/schema.sql`
4. انسخ URL و anon key إلى ملف `.env`

### الخطوة 4: الحصول على مفاتيح API المجانية

| الخدمة | الرابط | الطبقة المجانية |
|--------|--------|-----------------|
| Google Gemini | [aistudio.google.com](https://aistudio.google.com/app/apikey) | 15 طلب/دقيقة |
| Groq API | [console.groq.com](https://console.groq.com/keys) | مجانية بسخاء |
| Telegram Bot | [@BotFather](https://t.me/BotFather) | غير محدود |

### الخطوة 5: التشغيل

#### تشغيل بوت تليجرام:
```bash
python -m src.delivery.telegram_bot
```

#### تشغيل لوحة التحكم الويب:
```bash
streamlit run dashboard/streamlit_app.py
```

#### تحليل ملف من سطر الأوامر:
```bash
python scripts/run_analysis.py file path/to/contract.pdf
```

#### فحص المواعيد النهائية:
```bash
python scripts/run_analysis.py --check-deadlines
```

## 🔧 التكوين مع GitHub Actions

لتفعيل الجدولة التلقائية:

1. ارفع المشروع إلى مستودع GitHub
2. أضف المفاتيح السرية في:
   `Settings → Secrets and Variables → Actions`
3. المفاتيح المطلوبة:
   - `GEMINI_API_KEY`
   - `GROQ_API_KEY`
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

سيُنفّذ سير العمل يومياً تلقائياً، أو يمكنك تشغيله يدوياً من تبويب Actions.
